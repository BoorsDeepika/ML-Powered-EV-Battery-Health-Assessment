# ML-Powered-EV-Battery-Health-Assessment
## EV Swap ML-Powered Battery Health Assessment

An ML-powered Battery Health Assessment system for EV battery swapping stations that analyzes real-time battery parameters and predicts the overall health of an electric vehicle battery. The system uses machine learning to estimate State of Health (SoH), assess battery performance, and provide recommendations for battery replacement or continued usage.

Project Overview:

The system collects important battery parameters such as voltage, current, temperature, State of Charge (SoC), and charge cycles. These parameters are processed to extract relevant features and passed to a Random Forest machine learning model for battery health prediction.

The system also provides a charge pattern visualization and generates an assessment report containing the predicted battery health, confidence level, and recommended action.

Key Features:

* Real-time EV battery data monitoring
* Battery parameter analysis
* Feature extraction from battery data
* ML-based State of Health (SoH) prediction
* Random Forest classification/prediction
* Charge pattern visualization
* Battery health status and confidence score
* Recommendation for battery replacement or continued usage
* Operator authentication and data management
* Assessment report generation

Technologies Used:

* Random Forest
* Pandas & NumPy
* Matplotlib
* CSV Dataset
* UML / System Modeling
